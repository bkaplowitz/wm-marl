## Frozen representation probes

Fresh current-weight features are reconstructed from raw complete-episode
prefixes. All targets use the current state or future factual rewards; future
observations are never inputs to the root feature. Whole episodes are separated
into train/validation/test: 57/19/20 episodes and 1,487/520/570 local-decision
rows. Regularization and normalization use only training/validation data.

| Feature | Return R² H1 | H5 | H15 | Median observable R² | Median availability R² |

Raw observable reconstruction is an identity upper bound. Current SMAC
availability is also almost exactly linearly decodable from the raw observation.
The learned encoder preserves that signal. Sampling the discrete posterior
substantially reduces linear decoding of current observables, but return R²
remains similar to the posterior mean. This identifies a possible noisy
interface, not proof that a new value-gradient auxiliary loss is needed.
The H1 return is difficult for every feature on this replay distribution.

## Historical comparison and next experiment

The historical 50k-step 2s3z checkpoint used 64 roots, 29 episodes and 207
root-live slots. Its H5 self-fed return RMSE was .2668 versus .1947 under factual
history; excess MSE +.03325 [+.00868, +.06660]. Its mask FP/FN excesses were
approximately +5.3/+5.2 percentage points, both with positive conditional
intervals. Its model-return bias interval [-.1423, +.0295] included zero.
Both checkpoints therefore show recursive outcome degradation, while only the
fresh checkpoint shows clearly positive mean H5 return bias on its audited
cohort. Different training ages (10.5k versus 50k), seeds, policies, and replay
distributions prevent interpreting the difference as a causal effect of the
cooperative-return corrections.

A matched H2 imagined-PPO arm is the smallest next policy experiment. Keep the
factual critic anchor, cooperative return semantics, optimizer and data budget
fixed. H2 substantially reduces the observed recursive return and legality
errors, while retaining the critic bootstrap for longer credit. H2 still has
20.39% absolute mask FP and measurable excess liveness error; shortening is a
test of reducing exposure to inaccurate predictions, not a complete model fix
or a promised win-rate improvement.

In parallel, a model-only recurrent-training experiment can target the measured
failure: sampled joint prediction → local posterior → joint prediction, with
actual replay actions and correctly aligned availability, liveness and outcome
targets. Start with H2, frozen actor and local representation, and the same raw
history/current-weight root construction. Require held-out improvement on this
paired audit before promoting its world-model loss. Existing deterministic
multistep JEPA results do not validate this deployed sampled recurrence. The
present evidence favors this focused simulator comparison before adding a
general value-to-representation auxiliary objective.

Finite cumulative model return here uses predicted continuation products. It has
