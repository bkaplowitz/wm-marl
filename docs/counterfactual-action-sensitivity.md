# Counterfactual action-sensitivity diagnostic

## Recommendation

Use paired simulator counterfactuals as a small, held-out diagnostic before
considering them as a training objective. The diagnostic is useful because the
current metrics show whether predictions change under alternative actions, but
not whether those changes match the real environment. Integrating branched
simulator data into training would be substantially more complex, would consume
extra environment interactions, and would require privileged simulator access.

## Distinguish the two counterfactual proposals

Two related ideas should not be conflated:

1. A five-step imagined policy deviation asks whether taking an alternative
   action now and then returning to the policy produces a better imagined
   return. This is an actor/critic and exploration experiment. Because the
   branch is generated by the learned world model, it cannot validate that
   model's action effects.
2. A paired simulator transition starts from the same real SMAC state, holds
   history and teammates' actions fixed, changes one focal agent's action, and
   observes the real alternative successor. This directly tests whether the
   world model predicts action-induced changes correctly.

The second experiment is the appropriate action-sensitivity diagnostic.

## Why the existing objective is insufficient

The current action-margin objective enumerates legal focal-agent alternatives,
but compares every alternative prediction with the factual successor target. It
therefore encourages different legal actions to produce different predictions
even when their real outcomes are equal. Existing metrics such as
`action_counterfactual_prediction_change` can detect that predictions differ,
but cannot distinguish:

- correct sensitivity: the real and predicted action effects agree;
- missed sensitivity: the real effect is large but the predicted effect is
  small; or
- hallucinated sensitivity: the real effect is small but the predicted effect
  is large.

Paired simulator targets make these cases identifiable.

## Minimal experiment

### 1. Reproducibility gate

The repository's SMAC wrapper exposes seeded construction, reset, and step, but
no snapshot/restore interface. Test deterministic replay before building any new
machinery:

1. Construct two environments with the same held-out seed.
2. Replay the same recorded joint-action prefix in both.
3. At each step, compare observations, legal-action masks, reward, termination,
   and combat diagnostics.
4. Require agreement exactly or within a predeclared numerical tolerance.

Run this over 10--20 episodes. If matched replay does not reproduce the same
state, stop. Exact branching would then require lower-level SC2 state handling
and may not justify its engineering cost.

### 2. Small paired dataset

If replay is reproducible:

1. Select 32 held-out fork states across at least 10 episodes.
2. At each state, choose one alive focal agent with at least two legal actions,
   rotating the focal agent across states.
3. Hold all teammates' actions fixed.
4. Execute the factual joint action in one matched environment.
5. In separate matched environments, execute every other legal action for the
   focal agent.
6. Record the next observations, rewards, legal-action masks, alive state,
   termination, and combat diagnostics.

This smoke test should establish feasibility and reveal whether the effects are
nondegenerate. If it succeeds, expand to roughly 128--256 fork states and
bootstrap uncertainty by episode rather than treating alternatives from the
same episode as independent.

### 3. Match the current intervention

For each multistep horizon above one, the current objective preserves the
factual root and earlier action prefix and changes only the final action in the
window. The simulator diagnostic should mirror that intervention: replay the
shared prefix to the tail state, branch for one environment step, and use the
resulting alternative successor as the counterfactual target. A five-step
divergent simulator rollout is not needed for the initial test.

Use the same frozen EMA encoder that supplies the current training targets. For
the factual and counterfactual branches, define

\[
e_f = E_{\mathrm{EMA}}(o_{t+1}^f),
\qquad
e_c = E_{\mathrm{EMA}}(o_{t+1}^c),
\]

and compare them with predictions \(\widehat e_f\) and \(\widehat e_c\). The
counterfactual prediction must be evaluated against its own target \(e_c\), not
against the factual target \(e_f\).

## Measurements

Report the following on the same paired dataset for every checkpoint:

- factual prediction cosine
  \(\cos(\widehat e_f,e_f)\);
- counterfactual prediction cosine
  \(\cos(\widehat e_c,e_c)\);
- true effect magnitude
  \(D_{\mathrm{true}}=1-\cos(e_f,e_c)\);
- predicted effect magnitude
  \(D_{\mathrm{pred}}=1-\cos(\widehat e_f,\widehat e_c)\);
- absolute calibration error
  \(|D_{\mathrm{pred}}-D_{\mathrm{true}}|\);
- correlation between predicted and true effect magnitudes; and
- agreement between the true and predicted effect-vector directions.

Use repeated same-state, same-action branches to estimate the reproducibility
noise floor. From that threshold, report:

- the false-separation rate, where the predicted effect is material but the
  real effect is within the noise floor; and
- the missed-effect rate, where the real effect is material but the predicted
  effect is within the noise floor.

Stratify results by action type and policy probability. Also report raw
observation and combat-diagnostic changes so that insensitivity in the target
encoder is not misattributed to the transition model.

## Comparison and decision rule

Evaluate identical counterfactual pairs using matched checkpoints with the
action-margin coefficient at `0.1` and `0.0`.

- If the margin increases predicted separation without improving prediction of
  the alternative target, it is manufacturing sensitivity and should remain
  disabled.
- If the no-margin model misses genuinely different outcomes and the margin
  improves counterfactual-target accuracy, the margin is useful, although
  paired supervision would still be more principled.
- If both variants already predict alternative targets accurately, do not add a
  new objective.
- If both variants fail, consider a separate paired-supervision experiment only
  after checking whether errors are concentrated on rare or unsupported
  actions.

## Deferred work

Do not initially change PPO, GAE, actor or critic losses, replay sampling, or
imagined-action selection. Do not build joint-action trees or train on
model-generated pseudo-counterfactual targets. Simulator counterfactuals should
remain an evaluation-only diagnostic unless the held-out results show a clear,
policy-relevant failure that ordinary factual supervision cannot address.
